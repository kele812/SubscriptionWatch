来源 IP 核查

查询一个 IP 在各面板出现的请求。先看是否真正返回订阅，再打开“核查链路”查看直连 IP、IP 取值依据与请求编号。

这些记录能证明什么？

请求归属某个订阅，不等于账号本人发起。直连 IP 是 Xboard 实际连接的上游；如果使用反代，来源 IP 可能来自可信代理转发。请求编号可用于对照插件记录，但旧版插件没有编号。要核对反代日志，需在反代机器上按时间与 IP 另行查找。

指定用户采集

仅采集开启后新建立的连接，默认保留3天。目标域名不一定可用；记录不包含网页内容，也不代表网页访问成功。数据直接由节点发送至风控机。

必须与已采集的用户ID和邮箱一致。最多同时指定100名用户；停止后已有记录仍保留至到期。

            黑名单如何收集和生效
            

              记录开关开启后，各面板自动收集参与触发中国大陆多 IP 规则的有效
              IP；关闭后不新增、不更新。命中规则开关独立控制：新请求通过名单中的
              IP 成功获取订阅时标记可疑。用户白名单、IP 白名单和已启用的
              Cloudflare 豁免优先。
            

            

              默认保留7天，从最近参与触发的访问时间计算。999表示永久；缩短天数会限制现有条目，移除的旧证据不会自动恢复。导出为全部有效
              IP 的 TXT 文件，不受当前分页影响。

插件接入

            

              在对应 Xboard 安装 v3
              采集插件，填写下列三项。可信代理IP可保留当前有效配置。
            

            
            

          

          

            
面板设置

            
            
定时清理访问历史

            
            
每分钟清理超过保留天数的访问记录；可疑用户和评估历史不删除。

            
          


          

            
可疑用户自动封禁 Xboard 账号

            

              默认关闭。开启后仅对实时判断仍满足可疑用户的用户执行账号封禁；保留的过期风险标记不会单独触发封禁。封禁会修改Xboard用户状态；管理员和员工账号不会自动封禁。
            

            
            

              使用v3.5采集插件领取任务，无需填写Xboard地址或管理API凭据。任务约每分钟领取，关闭开关不会撤回已下发的任务；最长30秒内可能仍会执行。
            

            

              无观察期。开启后，符合当前判断条件的可疑用户将在插件下一次领取任务时执行封禁，通常约一分钟内。
            

            
            

            

          

          

            
手动解封 Xboard 账号

            
            
            

              需要v3.5插件。ID与邮箱必须匹配已采集用户；操作将取消旧风险，新的异常仍会重新评估。不恢复套餐、流量或到期时间。执行结果请查看上方历史。
            

            
          

          

            
数据管理

            

              清空访问历史不会删除可疑用户、评估历史或白名单。风险计算所需的短期证据最多保留7天，到期自动清理。
            

            
          

        

        

          

            
订阅审核与可疑用户规则

            

              新请求先由风控机审核。命中拦截时只跳转本次订阅；被标记为可疑的用户持续拦截，直到手动取消。取消后有新异常仍会重新标记。IP归属地判断依赖已安装的数据库。
            

            
用户白名单和来源 IP／域名白名单命中后，不受订阅风控规则限制，但仍记录访问。风控机失联或审核超时时，一律拒绝本次订阅。

            

              01 · 非指定客户端获取订阅
              
              

                新请求的完整 UA 不包含任何允许关键词时，只拦截本次订阅并跳转，不标记为可疑用户。UA 可以伪造，匹配不代表身份可信。
              

              
            

            

              02 · 多个中国大陆 IP 获取订阅
              
              

                默认同一用户最近60分钟出现第4个不同中国大陆IP，或720分钟出现第11个，就在触发的这次标记并跳转。重复IP只计一个，不区分UA。
              

              

                
              

              

                
              

            

            

              03 · 云服务器 IP 获取订阅
              
              

                匹配关键词的云服务器IP每次请求都跳转。同一用户60分钟内第3次，或720分钟内第10次云服务器请求时标记可疑；同一个IP重复请求也计数。关键词忽略大小写。
              

              

                
                
              

              

                
                
              

            

            

              04 · 多个非中国大陆 IP 获取订阅
              
              

                默认同一用户最近60分钟出现第4个不同非中国大陆IP，或720分钟出现第11个，就在触发的这次标记并跳转。港澳台计入，归属未知排除。同一IP只计一个。
              

              

                
              

              

                
              

            

            

              05 · 黑名单 IP 获取订阅
              
              

                开启后，所有面板共用的黑名单IP一旦请求订阅，就标记可疑并跳转。名单的自动收集和保留天数仍在“IP黑名单”页面设置。
              

            

            

              06 · 每日订阅请求上限
              
              
默认30次。成功下发和已拦截请求均计入；达到上限的请求仍按其他规则处理，第31次开始跳转。每日上限不会单独标记可疑用户。

            

            

              拦截后跳转
              
              
所有正常审核拦截统一返回302跳转，默认百度。修改后只影响新请求；风控机失联或审核超时时返回403。

            

            

              仅允许中国大陆或白名单 IP 获取订阅
              
              
开启后，来源 IP 不属于中国大陆且未命中用户白名单或下方 IP／域名白名单时，本次订阅直接跳转，不标记可疑用户。中国大陆 IP 仍需通过其他规则；归属地未知按非中国大陆处理。Cloudflare 豁免不能绕过此限制。

            

            

              不检查的访问来源
              
              

                例如：1.2.3.4 # 自有节点，或 vpn.example.com # 备用出口。域名由风控机定时解析 IPv4／IPv6；解析失败时不匹配白名单。白名单命中后不受所有订阅风控规则限制，包括每日次数与已有可疑标记；访问仍会记录。风控机失联时仍拒绝本次订阅。
