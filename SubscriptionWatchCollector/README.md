# 订阅观察采集器 v3.7.0

安装在 Xboard，配合独立风控后台 v3.7.0。先升级后台再更新插件，新加坡反代无需修改。

## 安装和更新

Xboard 插件管理上传 ZIP 安装或更新，填写风控 HTTPS 根地址、面板标识、采集密钥并启用。更新沿用原配置，不需要管理 API Authorization；不同 Xboard 不共用面板标识。

可信代理 IP 按实际链路填写。本项目已验证链路为 `203.0.113.10,127.0.0.1`，其他部署不能照抄。仅信任自己控制的代理。

沿用已有每分钟 Laravel scheduler，不重复添加计划任务；Octane 按原部署方式重载。约 1～2 分钟后后台显示插件通道已连接，自动封禁默认关闭，需手动开启。

## 采集与开销

通过 client.subscribe.before 和 Laravel RequestHandled 采集已认证用户 ID、邮箱、IP、原始 UA 及响应状态，写入独立前缀 Redis 缓冲。不存订阅 Token、节点配置或响应正文，不建立数据库表，不修改核心代码。插件配置和安装状态仍由 Xboard 保存。

订阅请求不等待风控 HTTP。每分钟最多上报 3 批、每批 100 条。默认缓冲 2000 条、有效期 1 小时；队列满、过期和 Redis 故障可能丢记录。Redis RDB/AOF 可能持久化临时数据。

## 可选封禁

每分钟采集上报后最多领取 3 条封禁任务。使用原采集密钥对请求和响应签名，绑定面板及随机请求标识，任务有效期 30 秒，无需新开 Xboard 控制端口。

风险由风控机评估。插件支持封禁与明确提交的手动解封，事务内核对 ID、邮箱、期限和管理员/员工身份，设置 banned=1 并调用 Xboard 会话清理服务，失败回滚。不改数据库结构；其他用户字段保持原值，ORM 可能更新修改时间。

执行前通过 Redis 去重并保存回执，Redis 不可用时不执行。回执最多 100 条、保留 7 天，重传直到后台确认。后台只下发一次，执行失败或结果丢失显示“失败或待核对”，需人工核对 Xboard，不自动重新执行该任务。

关闭开关不会撤回已领取且未过期的任务；风险解除或加入白名单不会自动解封；手动解封任务仅修改banned=0。更换面板归属或密钥前先处理原缓冲和待确认任务，避免记录错归或回执遗失。

风险计算、IP 数据库、历史和 TG 全在风控机。Xboard 有少量采集、每分钟网络请求及封禁必要操作开销，不是零开销。普通采集不写用户业务表；实际封禁会修改用户状态并删除登录会话。

## 验证

PHP 8.2 语法解析及 PHP 8.5 模拟 Xboard/Redis/HTTP 执行测试通过，覆盖签名、隔离、重复任务、身份检查及回滚。真实 Xboard/Octane/Redis 仍需使用测试账号验收。

新增上报失败计数（Redis可用时记录、七天过期）；通过ban-v2能力标识支持手动解封，仍每分钟最多三个控制任务。默认30分钟封禁观察和通知合并全部在风控机执行。
